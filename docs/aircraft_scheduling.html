Multi-Year Aircraft Fleet Scheduling with Beam Search

Reproduction & Extension of Deng, Santos & Curran (EJOR 2020)

Beam search tames the combinatorial explosion. 45 aircraft, 4 years, under 4 minutes — a baseline ready for MCTS and learned heuristics.
1 - Problem

Maintenance Check Scheduling

Aircraft require periodic maintenance. Each plane tracks 3 counters that increment over time:

DY = calendar days FH = flight hours FC = flight cycles (takeoffs)

When any counter hits its regulatory limit, the aircraft must undergo maintenance. A check resets all counters to zero.

A-check light inspection, ~1 day, limit: 750 FH
C-check heavy overhaul, 10-30 days, limit: 7500 FH
The Scheduling Trade-off
Tolerance: A regulatory buffer (e.g., +75 FH for A-checks). Requires approval from aviation authorities. Using it is costly and should be avoided in planning.
Penalty: If tolerance is used, the extra FH/DY/FC must be deducted from the next interval. Borrow now, pay later.
Combinatorial complexity: 45 aircraft share limited hangar slots. Scheduling one plane affects when others can go. Combinatorial explosion over a 4-year horizon.
2 - Model

MDP Formulation

We model the problem as a deterministic finite-horizon MDP with daily time steps over T = 1461 days (4 years).

State (all N aircraft)
$$s_t = \{(DY^A_i, FH^A_i, FC^A_i, DY^C_i, FH^C_i, FC^C_i)\}_{i=1}^{N}$$
6 counters per aircraft × 45 aircraft = 270 dims
Action (how many checks today)
$$a_t = (n_A, n_C) \in \{0,1,2\} \times \{0,1,2,3\}$$
7 valid combinations (Table 2) × priority rule → concrete schedule
Worked Example: One Day Step
Stage Cost (Eq. 28)
$$c_t(s_t, a_t) = \underbrace{\sum_{i \in a_t} (I^{FH} - FH_i)}_{\text{wasted FH}} + \underbrace{P_\theta \cdot \theta_t}_{\substack{\text{tolerance}\\\text{penalty}}} + \underbrace{P_\eta \cdot \eta_t}_{\substack{\text{grounding}\\\text{penalty}}}$$
Wasted FH: Primary cost. Use aircraft closer to limit.
Tolerance (θₜ): Any aircraft over limit? $P_θ = 10^8$
Grounding (ηₜ): Any aircraft stuck? $P_η = 10^8$
Objective: $\displaystyle\min_\pi \sum_{t=1}^{T} c_t(s_t, \pi(s_t))$. Minimize total wasted FH while avoiding tolerance/grounding.
3 - Algorithm

Thrifty DP = Beam Search

With N=45 aircraft and T=1461 days, backward DP is intractable. We use forward beam search: at each day t, apply one of 7 actions to each state, prune infeasible successors via workability check, then aggregate by utilization histogram keeping only the best state per bucket.

Per-Day State Expansion and Pruning
Workability (Thrifty Check): A state is "workable" if a greedy simulation (always check most urgent aircraft first) can reach horizon T without any aircraft being grounded (η=0). If greedy fails, no policy can succeed → prune early.
State Aggregation: Compute mean utilization ū = (1/N)Σ(FHᵢ/Iᶠᴴ) for both A-checks and C-checks. Discretize with Δu=0.1 → 11 buckets each. Keep only lowest-cost state per bucket → max 11×11 = 121 states/day.
Complexity: O(nₐ · T² / Δu²), quadratic in horizon, not exponential. With B≤121 states and 7 actions, we evaluate ~850 successors per day × 1461 days ≈ 1.2M states total.
4 - Input Data

Planning Problem Setup

The input combines a fleet snapshot (Sept 25, 2017) with 4 years of operational constraints. We plan forward while respecting periods when aircraft are needed for peak travel demand.

Input → Output
Fleet: 21 A320 + 14 A319 + 10 A321
Limits: C: 7500 FH (±500), A: 750 FH (±75)
Peak seasons: Jun–Sep (high travel demand)
Goal: minimize wasted FH, zero groundings
5 - Extensions

"Forward DP" as Beam Search

The paper calls this "practical dynamic programming," but recognizing it as beam search unlocks decades of AI/OR improvements:

Beam search literature offers:
• Best-first vs. breadth-first expansion
• Heuristic guidance (f = g + λh)
• Variable beam width
• Stochastic beam search
• Diverse beam search

Our variants tested:

① Baseline: Paper's FIFO expansion

② +Heuristic: h = "time to next grounding risk"

③ +Best-first: Expand lowest f(s) = g + λh first

Best-first + heuristic → 16% cost reduction vs. baseline (zero groundings maintained)
